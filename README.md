# MedianKit

MedianKit is a statistical calculator Android application built with modern Android development practices and Jetpack Compose. It allows users to quickly and accurately calculate the median, mode, quartiles, and range from a dataset.

## Features

- **Statistical Calculations:** Easily calculate Median, Mode, Quartiles, and Range for a dataset.
- **Five-Number Summary:** Get the Min, Q1, Median, Q3, and Max values of a dataset.
- **Box Plot Visualizations:** Visualize your dataset using intuitive box plots.
- **Calculation History:** Keep track of your previous calculations and review them later.
- **App Settings & Theming:** Support for different theme modes (Dark, Light, System) and dynamic colors.
- **Modern UI:** Built entirely using Jetpack Compose with Edge-to-Edge support.

## Tech Stack

- **Kotlin:** 100% Kotlin codebase.
- **Jetpack Compose:** Modern, declarative UI toolkit.
- **MVVM Architecture:** Using ViewModels and Repositories to separate concerns.
- **StateFlow & Coroutines:** For reactive state management and asynchronous operations.
- **Jetpack Navigation:** Compose navigation for seamless transitions between screens.
